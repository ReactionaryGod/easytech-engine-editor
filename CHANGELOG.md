# Changelog

## 0.1.0

First release.

- **World Conqueror 4 1.30.0:** engine extension (skill/perk Types up to 511, "behaves like", stat effects), patch
  switches (challenge caps, Mysterious Forces picker, General Bank, elite-skin effects), custom skills and perks with
  texts in 7 languages, icons, and general/unit assignments.
- **Glory of Generals 3:** skills, perks, buffs and conditions (`def_buff.xml`) editor; buff-type reference decoded
  from `libiron.so`; icons; texts in 5 languages. Edits are written straight into the mod package.
- **Code browser** for both libraries: functions, strings, disassembly, cross references, assemble-and-patch.
- Safe builds from the original library with site verification, backups and `CHANGES.txt`.
- Flet (Flutter) desktop UI with a game switcher.
